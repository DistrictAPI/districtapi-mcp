# Security Policy

## Reporting a vulnerability

Please report security issues **privately** via GitHub's
[private vulnerability reporting](../../security/advisories/new) on this
repository, rather than opening a public issue.

If that is unavailable, email **security@districtapi.dev**.

Please include enough detail to reproduce: the affected tool or endpoint, the
input used, and what you observed. A proof-of-concept against your own API key
is welcome; please do not test against other users' data.

I am a solo maintainer — expect an acknowledgement within a few days. There is
no paid bounty, but I am glad to credit you in the fix and release notes if you
would like.

## Scope

This repository is the MCP server. The REST API it calls lives at
`districtapi.dev`; issues there are in scope too and can be reported the same way.
